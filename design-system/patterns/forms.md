# Forms

Two input styles exist in the export.

| | Invitation maker (`.inv-in`) | Camp registration (`.reg-in`) |
|---|---|---|
| Fill | white | `#f6f5f1` |
| Border | `#e0ddd5` | `#e3e0d8` |
| Radius | 10 | 10 |
| Text | 600 14px | 600 14px |
| Focus | ink border + 3px `rgba(33,31,27,.08)` ring | accent (orange) border, white fill |
| Label | Archivo 700 11px uppercase .05em `#8a877f` | Archivo 700 11px uppercase |

Selected option (invitation): `#fffbe6` fill, 2px yellow border. Selected chip (camp): orange
border, `#fff7ef`, check icon.

Drift item D5 asks to pick one input style for the site.
