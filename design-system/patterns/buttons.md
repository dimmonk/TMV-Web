# Buttons

One family, weight-only variants. Archivo 800, uppercase, .03em.

| Variant | Look | Where |
|---|---|---|
| Primary | Yellow fill, ink text, radius 11 to 12, padding 14px 22px (15px 24px in heroes) | The one main action |
| Dark | Ink fill, white text, radius 10 to 11 | Secondary action on light backgrounds, card actions (Reserve, Book with coach) |
| Ghost (light) | Transparent, ink text, 1.5px `#ddd9d0` border | Tertiary on light |
| Ghost (dark) | Transparent, white text, 1.5px `rgba(255,255,255,.25)` border | Second action in dark heroes |
| Text link action | Archivo 800 13 to 14px uppercase, arrow in the category colour, gap grows on hover | Card actions |
| Header Book Now | Yellow, 800 13px, padding 11px 15px, radius 9 | Header only |

Hover: lift 1px (buttons) or arrow gap 7 to 11px (links).

Live `.btn-primary`, `.btn-dark`, `.btn-ghost`, `.btn-ghost-light` in `global.css` match.
Get Started step 1 in the design uses an ink waiver button, not yellow.
