# MobileTabBar

The fixed bottom tabs below `bp-md`: `rgba(28,26,23,.92)` with a 14px blur. Five tabs: Home, Classes, Book, Schedule, More. Active white, inactive white at 42%.

Book is a raised `yellow` circle. Live is 64px raised 36px; the export is 54px raised 30px (drift M1 recommends 54px). The tab label is Classes, matching the desktop nav (drift M2). More opens a bottom sheet over the page (drift M3).

Each page sets which tab lights up (`mobileTab`).
