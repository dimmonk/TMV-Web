# Input

Two input styles exist and both stay for now (drift D5).

| | Invitation maker (`.inv-in`) | Camp registration (`.reg-in`) |
|---|---|---|
| Fill | `card` | `#f6f5f1` |
| Border | `#e0ddd5` | `#e3e0d8` |
| Radius | 10px | 10px |
| Text | 600 14px | 600 14px |
| Focus | `ink` border and a 3px ink 8% ring | `cat-camps` border, white fill |
| Label | Archivo 700 11px uppercase .05em `muted-2` | same |

Selected option: invitation `#fffbe6` with a 2px yellow border; camp chip a `cat-camps` border on `warn-fill` with a check. Errors use `error-text` on `error-fill`, always with a sentence that says how to fix it.
