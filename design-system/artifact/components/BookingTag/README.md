# BookingTag

Says how a thing is booked before anything else is read. The final form is the solid chip: `radius-tag`, padding 6px 12px, Archivo 800 10.5px .07em uppercase, category fill, white text (`athletic-ink` on the light athletic fill, class `light`).

| Words | Meaning |
|---|---|
| Drop-in | Just come, no reservation |
| By appointment | Reserve a time online |
| Membership | Join any time |
| Register | Sign up for dated sessions (camps) |
| Direct with coach | Partner classes, paid with the coach |

Use it only when cards in one group mix booking types; skip it when they all book the same way, and never on intro tiles. The pill row never repeats it.

The export also carries a tinted version (Design Language hub) and an outlined one (Booking Tag Options). Drift K2 recommends the solid one only.
