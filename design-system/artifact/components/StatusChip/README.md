# StatusChip

A small state on a card: green means status, never decoration. Archivo 700 10px .09em uppercase, `radius-pill`.

- `tmv-chip go`: `go-text` on `go-fill` (No reservation, Booking now).
- `tmv-chip info`: `info-text` on `info-fill`.
- `tmv-chip`: neutral, `ink` on `tile` (Reservation required).
- `tmv-chip dur` + `--accent`: the duration chip, category at 13%.

Schedule tags use the same shape: New in `go-text` on `go-fill`, Ending in `ending-text` on `ending-fill`. Each state carries a word, never colour alone.
