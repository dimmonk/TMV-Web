# SectionHeader

The numbered heading that opens every content section.

- Eyebrow: Archivo 700 12px .14em uppercase in `faint`, with the number (800, accent) and a 14 by 2px accent bar.
- Title: `section-title` (Archivo 800, clamp(23px, 5.4vw, 34px), 1.06, -.018em), max 680px, balanced wrap.
- Description: `body` in `muted`, max 600px, 12px above.
- Optional action: Archivo 800 13px uppercase with a 2px accent underline.

Props: `num`, `eyebrow`, `title`, `description`, `align` (left, center), `theme` (light, dark), `category` (its colour replaces yellow as the accent), `actionLabel`, `href`. On ink: title white, description white at 70%, eyebrow at 50%.

Note: the `faint` eyebrow is 2.1:1 on paper; kept as the source has it.
