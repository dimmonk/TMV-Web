# CtaBand

Big link cards that close a page, in a grid of one to three columns, gap 18px.

- Card `radius-card`, padding 28px 30px. Dark: `ink`, white text, icon tile white 10%, eyebrow and arrow `yellow`. Light: `card`, `line` border, icon tile yellow 22%, eyebrow `faint`.
- Icon tile 46px `radius-btn-lg`; eyebrow Archivo 700 11px .13em; title Archivo 800 23px.
- Hover lifts 3px and moves the arrow 4px. Stacks to one column on phones.

Default pair: Price List (dark) and Group Class Schedule (light).
