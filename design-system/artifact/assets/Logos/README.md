# Logos

- `tmvlogo.png`: the monkey mark, full colour on a transparent ground (306 by 297). Use at 40px in the desktop header, 38px in the footer, 32px in the phone app bar, always on `ink`.
- `tmv-wordmark.png`: the THE MONKEY VAULT wordmark as an image (2100 by 480, opaque). The site sets the wordmark as live text instead (Archivo 900 uppercase in `yellow`), so use this file only where text cannot be used.
