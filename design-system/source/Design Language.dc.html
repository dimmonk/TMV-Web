Category colour marks identity, not action
Brand yellow = action
Every primary / conversion CTA is yellow on ink, on every page. It's a functional signal — "this is the button" — so it must read the same everywhere. A day-pass button is yellow, not green.
Category = identity
The category colour marks what you're booking — accent bar, arrow, category pill. It never fills a CTA, or button colour stops meaning "button" and just repeats the identity you already read.
Green = status
Green is reserved for the go status chip ("no reservation needed"). A green Open-Gym CTA would blur status with action — one more reason CTAs stay yellow.
Optional: a secondary / ghost button inside a category-themed block may take a thin category-coloured border to tie it to its section. The filled primary CTA stays yellow.

05 — Component Documented ★ Hero component

The Class Card

ClassCard.dc.html

The most important piece on the site — it sells every class. The whole design language flows from its idea: a front for the at-a-glance scan, a back one tap away for the detail that closes the decision. It already has a full written spec.

Open full spec
Live preview Tap a card to flip it
Pattern — the booking-method tag

The small squared-off badge above each title — Drop-in, By appointment or Membership (plus Register on dated sessions like camps) — sets the commitment before anyone taps in. It's deliberately drawn differently from the rounded key-info pills below it, so it reads as its own signal site-wide: see this tag, know how to book. Both ClassCard and BookingCard take it via the same booking-tag prop — set it whenever a card sits next to others with a genuinely different booking model; skip it when every card on the page books the same way.

Jump Nav

JumpNav.dc.html

The sticky in-page section bar — sits just under the header on any long page and lets people skip to a section. One component, used everywhere: Train, Events, Book Now and this page all mount the same JumpNav. It scroll-spies the page and highlights the section you're in, takes optional right-aligned quick links, and is driven by a single pipe-delimited items string.
