# Design: Don't Overdo Visual Accents

No single-side colored borders (`border-left`/`border-top` accent strips) on callouts or cards; the user
finds them "overused and ugly". To show state or emphasis use a background tint, typography weight or
size, spacing and grouping, an icon or colored dot, or a full border on all sides. No decoration for its
own sake: the default is no accent unless it communicates something. Before inventing a new card style,
extend the design system's existing one.
