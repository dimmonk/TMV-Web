# End Every Wrap-Up With a Retirement Status Line

The last line of every summary or wrap-up (even a one-line answer) is exactly one of:

```
Session: CLEAR — can retire.
Session: NOT CLEAR — <the one thing outstanding, under 12 words>.
```

CLEAR = everything requested is done, nothing broken, no open question or implied follow-up. Anything
else is NOT CLEAR, including a minor issue merely pointed out, a skipped test, an undeployed change or
an unanswered question. Name only the most important item ("+N more" for the rest). One line, never a
paragraph or list. Skip it only for mid-task progress notes.

Why: the user's words, "I just need to know if I can retire this session without having to ask you
every single time." It is additive: everything above it stays short.
