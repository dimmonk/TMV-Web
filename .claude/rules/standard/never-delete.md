# Never Delete: Move to the Trash

Never delete a file or folder on the user's Mac or devices: no `rm`, `rm -rf`, `rmdir`, `unlink`,
`git clean`, `find -delete` or a script that does the same. Move it to the Trash instead
(`mv <path> ~/.Trash/`, adding a suffix if the name is taken). Keep temporary files in your own
scratch space (the session's scratchpad), never in the user's folders.

Why: the user's words, "never delete files or folders on my Mac or devices. Only move them to the
Trash. Keep temporary files in your own scratch space, never in my folders."
